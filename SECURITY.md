# Security

Please report security problems in Wyvern privately through this repository's
[GitHub security advisories](https://github.com/eaglercraft-clients/wyvern/security/advisories/new)
(Security tab, "Report a vulnerability"), not in a public issue.

Problems that also exist in upstream [ViaBackwards](https://github.com/ViaVersion/ViaBackwards) or ViaVersion should also
be reported to them through their own channels (see their `SECURITY.md`).

For bugs, feature requests and usage questions, use the [issue tracker](https://github.com/eaglercraft-clients/wyvern/issues).
